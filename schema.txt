Dataset / Corpus Schema
=======================

Project structure
-----------------
Working database: MySQL
Publication / exchange format: CSV
Repository: GitHub
Optional later addition: TEI-annotated colophon files

Core tables
-----------
1. manuscripts 
        manuscripts.csv = information about the codex/work
2. colophons
        colophons.csv = identity + location + textual/content information
3. morphology
        morphology.csv = visual/codicological configuration of that colophon


Relationship
------------
One manuscript can contain one or more colophons.

manuscripts.manuscript_id
        |
        | 1 : n
        v
colophons.manuscript_id

Each colophon will later have its own morphology record.
